## 1. Git 四大工作區域核心流向

在將檔案推送到 GitHub 之前，務必了解檔案在 Git 內部的流動狀態：

```mermaid
graph LR
    A[工作目錄<br>Working Directory] -- "git add" --> B[暫存區<br>Staging Area]
    B -- "git commit" --> C[本機倉庫<br>Local Repository]
    C -- "git push" --> D[遠端倉庫<br>Remote: GitHub]
```

- **工作目錄 (Working Directory)**：您目前正在編輯的檔案實體（未追蹤或未暫存）。
- **暫存區 (Staging Area / Index)**：透過 `git add` 準備提交的清單。
- **本機倉庫 (Local Repository)**：透過 `git commit` 將快照存入電腦本地的歷史紀錄（仍在自己電腦上）。
- **遠端倉庫 (Remote Repository)**：透過 `git push` 上傳至 GitHub 雲端伺服器。

## 2. 防護首重：設定 `.gitignore` 防止機密外洩

> [!CAUTION]
> **絕對不要將帳號密碼、API 金鑰 (`.env`)、私人密鑰、暫存檔或大型依賴套件 (`node_modules`) 推送到 GitHub！** 一旦推送到公開儲存庫，會立刻被網路機器人爬取造成重大資安漏洞。

在執行任何 Git 指令前，請在專案根目錄建立 `.gitignore` 檔案：

```gitignore
# 敏感資訊與環境變數檔案 (千萬不能上傳)
.env
.env.local
.env.*.local
*.pem
*.key
credentials.json
secrets.json

# 依賴套件目錄 (體積巨大且可透過 package.json 重新安裝)
node_modules/
vendor/
venv/
__pycache__/

# 編輯器與 IDE 設定檔
.vscode/*
!.vscode/settings.json
!.vscode/extensions.json
.idea/
*.swp

# 編譯產物與暫存日誌
dist/
build/
out/
*.log
npm-debug.log*

# 作業系統暫存檔
.DS_Store
Thumbs.db
desktop.ini
```

## 3. 步驟 1：本地專案初始化與首次提交

開啟終端機並切換至您的專案目錄（例如 `c:\CustomApp\HowToUseGitHubForVSCode`）：

### 3.1 初始化 Git 儲存庫
```bash
git init
```
> 執行後，Git 會在專案根目錄下建立一個隱藏的 `.git` 資料夾，代表此目錄已受 Git 版本控管。

### 3.2 檢查檔案狀態
```bash
git status
```
未追蹤的檔案會以紅字顯示。確認 `.gitignore` 有正常發揮作用（`.env` 等機密檔案不應出現在清單中）。

### 3.3 加入暫存區
```bash
# 加入當前目錄下所有的變更
git add .
```
再次輸入 `git status`，被加入暫存區的檔案會變成綠色。

### 3.4 進行第一次本機提交 (Commit)
```bash
git commit -m "feat: 首次提交專案"
```

## 4. 步驟 2：在 GitHub 上建立遠端儲存庫 (Repository)

1. 登入 [GitHub](https://github.com/)。
2. 點擊頁面右上角的 **`+`** 圖示，選擇 **New repository**。
3. 填寫儲存庫資訊：
   - **Repository name**：輸入專案英文名稱（例如：`HowToUseGitHubForVSCode`）。
   - **Description**（選填）：簡述專案用途。
   - **Public / Private**：
     - *Public*：公開，所有人皆可檢視（適合開源專案）。
     - *Private*：私有，僅您與被邀請的協作者可見（適合商業或個人隱私專案）。
   - **重要注意事項**：
     - ⚠️ **不要勾選**「Add a README file」
     - ⚠️ **不要勾選**「Add .gitignore」
     - ⚠️ **不要勾選**「Choose a license」
     *(因為我們本地端已經建立好專案與檔案，勾選會導致遠端與本地端歷史不一致而需要額外解決合併)*。
4. 點擊最下方的 **Create repository** 按鈕。

---

## 5. 步驟 3：連結遠端儲存庫並推送到 GitHub

建立完成後，GitHub 頁面會顯示指令教學。請複製其中的「**…or push an existing repository from the command line**」指令：

```bash
# 1. 確保目前主要分支名稱為 main
git branch -M main

# 2. 將本地儲存庫與 GitHub 遠端倉庫建立連結（命名為 origin）
git remote add origin https://github.com/<您的GitHub使用者名稱>/<您的儲存庫名稱>.git

# 3. 將本機 main 分支推送到遠端 origin，並設定為預設上游分支 (-u)
git push -u origin main
```

### 首次推送身分驗證
- 執行 `git push` 後，系統會跳出 **Git Credential Manager** 視窗。
- 點選 **Sign in with your browser**。
- 瀏覽器完成點擊授權後，終端機即會開始上傳並顯示上傳進度（如 `Writing objects: 100%`）。
- 重新整理 GitHub 網頁，即可看到您的程式碼已經成功發布！

## 6. 在 VS Code 介面中一鍵發布專案 (GUI 方式)

如果您不想使用指令列，VS Code 提供了更直覺的圖形化上傳方式：

1. 在 VS Code 中開啟專案資料夾。
2. 切換到左側 **原始檔控制 (Source Control)** 面板（快捷鍵 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd>）。
3. 如果尚未初始化，面板會顯示 **Initialize Repository** 按鈕，點擊它。
4. 在上方輸入框填寫 Commit 訊息（如 `Initial commit`），點擊 **Commit**。
5. 接著面板中會出現一個藍色的 **Publish Branch to GitHub** 按鈕。
6. 點擊後，VS Code 會在視窗上方彈出選單：
   - 選擇 **Publish to GitHub public repository** (發布為公開專案)
   - 或 **Publish to GitHub private repository** (發布為私有專案)
7. VS Code 會在背景自動連線 GitHub API 建立遠端儲存庫並推送全部代碼，完成後右下角會提示「Successfully published」！
