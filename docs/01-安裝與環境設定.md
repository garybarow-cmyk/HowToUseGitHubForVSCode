## 1. Git 安裝與驗證

### 1.1 檢查是否已安裝 Git
請開啟終端機（Windows 請按 <kbd>Win</kbd> + <kbd>X</kbd> 選擇 **PowerShell** 或 **終端機**）：
```bash
git --version
```
- 如果顯示類似 `git version 2.x.x.windows.x`，表示系統已安裝 Git。
- 若提示「無法辨識的命令」，請依下方步驟安裝。

### 1.2 Windows 下載與安裝步驟
1. 前往 Git 官方網站下載：[https://git-scm.com/download/win](https://git-scm.com/download/win)
2. 下載 **64-bit Git for Windows Setup** 安裝檔並執行。
3. **重要安裝選項建議**：
   - **Choosing the default editor used by Git**：建議選擇 `Use Visual Studio Code as Git's default editor`。
   - **Adjusting the name of the initial branch in new repositories**：選擇 `Override the default branch name for new repositories` 並指定預設名稱為 `main`。
   - **Adjusting your PATH environment**：選擇 `Git from the command line and also from 3rd-party software`（推薦）。
   - **Choosing credential helper**：勾選 `Git Credential Manager`（這能幫您自動儲存 GitHub 帳號密碼，避免每次推送都要打密碼）。

## 2. 設定本機 Git 開發者身分

每次進行版本提交 (Commit) 時，Git 都會記錄作者的姓名與電子郵件。安裝完後必須進行全域設定：

```bash
# 設定您的英文姓名或暱稱（會公開顯示在 GitHub commit 記錄中）
git config --global user.name "Your Name"

# 設定您的 GitHub 註冊信箱
git config --global user.email "your_email@example.com"
```

### 驗證設定是否成功
執行以下指令檢查全域設定：
```bash
git config --list --global
```
您應該會看到剛剛設定的 `user.name` 與 `user.email`。

## 3. Windows 換行符號設定

Windows 系統預設使用 `CRLF` (`\r\n`) 作為換行符號，而 Linux、macOS 與 GitHub 雲端環境則使用 `LF` (`\n`)。

為了避免團隊協作時出現大量虛假的「整行都被更動」警告，請在 Windows 上執行：

```bash
# 讓 Git 在 check-in（提交）時轉為 LF，在 check-out（取出至本地）時轉為 CRLF
git config --global core.autocrlf true
```

## 4. GitHub 帳號註冊與登入驗證

### 4.1 註冊 GitHub 帳號
1. 前往 [github.com](https://github.com/) 點擊右上角 **Sign up**。
2. 輸入您的 Email、建立高強度密碼與使用者名稱 (Username)。
3. 完成人機驗證與收信驗證碼即可完成註冊。

### 4.2 GitHub 認證機制說明
GitHub 目前**不再支援直接使用純密碼**進行指令列推送 (`git push`)，常見的兩種安全授權方式為：
- **方式 A（最推薦給新手）**：透過 **Git Credential Manager** 搭配瀏覽器網頁 OAuth 點擊登入（首次 push 或透過 VS Code 登入時會自動跳出瀏覽器視窗授權）。
- **方式 B（進階開發者）**：使用 **SSH Key** 密鑰對登入，免除視窗彈出干擾。

## 5. 在 VS Code 中登入與授權 GitHub

VS Code 內建了深度整合的 GitHub 授權模組，登入後即可在編輯器內一鍵發布專案、拉取代碼與審查 PR。

### 登入步驟：
1. 開啟 **VS Code**。
2. 檢視左側活動列最下方的 **「個人頭像 / 帳號圖示 (Accounts)」**（齒輪上方）。
3. 點選 **Sign in with GitHub to use...**。
4. 系統會跳出提示視窗詢問是否允許開啟外部網站，點擊 **Open (開啟)**。
5. 瀏覽器會自動跳轉至 GitHub 授權頁面，點擊綠色的 **Authorize Visual Studio Code** 按鈕。
6. 瀏覽器提示跳回 VS Code 時，點選 **Open Visual Studio Code**。
7. 回到 VS Code，右下角會顯示登入成功訊息，此時左下角帳號圖示會顯示您的 GitHub 大頭照。
